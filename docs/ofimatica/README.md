# Aplicaciones Ofimáticas – Proyecto Intermodular

En esta carpeta se incluyen los documentos del módulo 0223 – Aplicaciones Ofimáticas.

## Documentos incluidos
- Documento descriptivo de la empresa.
- Inventario de equipos informáticos.
- Registro de incidencias.
- Presentación del sistema informático.

Todos los documentos han sido creados utilizando herramientas ofimáticas y simulan la gestión informática de una empresa real.
